# Historical demonstration outputs

All three remaining figures, `ig_tinyllama.png`, `ig_rdt.png`, and `per_step_sanity_ep002_t02.png`, are historical examples, not current validation results. Their old log-pi/nats labels and interpretations belong to the superseded analysis. In the current study, the historical logpi target is an auxiliary action discrepancy, not the diffusion policy log likelihood. The old ResNet, ViT and LLaVA photograph-based figures were removed from the current tree because their redistribution provenance is unresolved. See [NOTICE](../NOTICE).

Current demonstration contracts are documented in [the TinyLlama guide](../docs/ig_tinyllama.md) and [legacy workflow disposition](../docs/legacy_workflows.md). They do not qualify a numerical setting or establish the current paper's scientific conclusions.

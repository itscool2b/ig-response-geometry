# Historical notebooks

Both notebooks in this directory are preserved historical analyses. Their saved numerical outputs, units, thresholds, pass/fail labels and interpretations must not be treated as current conclusions. The notebooks contain earlier claims that the current paper has narrowed or corrected. They are not current reproduction entrypoints, and running them can overwrite historical figure files.

Use [the current paper](../paper/paper.pdf), [the saved-data reproduction guide](../analysis/revision/README.md), and [the paired rescoring analysis](../analysis/paired_rescoring/README.md) for the current study. The notebook contents are retained unchanged so their history can be inspected.

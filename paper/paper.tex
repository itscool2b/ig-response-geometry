\begin{abstract}
% audit-anchor: abstract
An explanation of a robot's actions can be tested by removing or restoring inputs and measuring changes in its predictions. We ask whether the rule used to score those changes alters the evaluation. For a robot diffusion policy, we distinguish the quantity being explained from the scoring response and compare squared action discrepancy (Q) with stabilized distance (N). An exact identity shows that N cannot increase normalized insertion or deletion area under the curve (AUC) when partial input replacement changes predictions no more than replacing all features with their baselines. Larger changes, called overshoots, can reverse this effect. In saved PickCube runs with no successful episodes, all eight paired median Q-minus-N differences are positive, but extreme observations make six means negative. Historical RDT-1B vision medians are also positive in successful and failed episodes. A new experiment compares seven rankings of input importance across three groups of robot-policy runs, using matched controls. The method with the highest mean advantage over random feature orders changes with the response in every group's vision-deletion comparison. Only one adjusted comparison provides statistical evidence separating the two highest means. For 32-bit model calculations, more integration points reduce the relative gap between summed input contributions and the target's change from baseline to actual input. Reduced precision leaves a gap across the tested budgets. These limited samples neither estimate general failure rates nor verify the original rankings. Scoring responses can change practical comparisons; numerical accuracy and ranking quality require separate assessment.
\end{abstract}

\textbf{Keywords:} integrated gradients, attribution evaluation, diffusion policies, perturbation metrics, numerical integration, robotics

\section{Introduction}

% audit-anchor: intro-task
\subsection{Explaining robot actions}

A robot policy predicts actions from its observations. To evaluate which inputs matter to a prediction, insertion and deletion tests restore or remove features in the order of importance assigned by an attribution method\citep{petsiuk2018rise}. The resulting action changes need a numerical score. This choice is less immediate for a vector of action coordinates than for a single model output\citep{zhang2026embodied}.

Diffusion policies generate action sequences by denoising predictions conditioned on observations\citep{chi2023diffusion}. We study the Robotics Diffusion Transformer (RDT)\citep{liu2024rdt} using Integrated Gradients (IG), which integrates sensitivity along a path from a chosen baseline to the input\citep{sundararajan2017axiomatic}. We distinguish the scalar quantity being attributed, the \emph{target}, from the \emph{response} that scores subsequent input changes. Either choice can be specified without requiring the other to be identical.

% audit-anchor: intro-evaluation
\subsection{What an evaluation score measures}

Removal-based evaluations combine an intervention, model behavior and a summary of that behavior\citep{covert2021explaining}. Each choice affects interpretation: retraining after removal\citep{hooker2019roar}, information exposed by masks\citep{rong2022road}, and disagreement among perturbation metrics\citep{tomsett2020sanity} all require care. Insertion/deletion AUC retains feature order but discards attribution magnitudes\citep{gomez2022metrics}. Meta-evaluation therefore tests the reliability of the metrics themselves\citep{hedstrom2023metaquantus}. Occlusion strategy can change method rankings\citep{blucher2024decoupling}; deletion benchmarks also find sensitivity to response/logit choices, references and patch settings\citep{wang2024trace}. Baseline choice can change the question answered in regression\citep{mamalakis2023baseline}.

Removed features may create inputs outside the training distribution\citep{hase2021ood}. Recent approaches address different parts of this problem. F-Fidelity fine-tunes on random masks and checks consistency across removal budgets, thereby evaluating an adapted model\citep{zheng2025ffidelity}. Diffusion-based reconstruction reduces detectable distribution shifts in image-classifier evaluations\citep{zhu2026fud}; it does not establish the cause of robot-policy overshoots here. Missingness-bias calibration learns an affine correction to classifier logits\citep{sridhar2026missingness}. That operation differs from subtracting a common random-order reference or rescaling an AUC in our comparisons.

% audit-anchor: intro-policy
Policy explanations also depend on which behavior is being evaluated. Counterfactual tests challenge saliency-based hypotheses in reinforcement learning\citep{atrey2020exploratory}, while action preference and state value pose different evaluation questions\citep{huber2022benchmarking}. StateMask randomizes actions to identify time steps important to reward\citep{cheng2023statemask}. Input attribution has also been applied to robotic torque outputs\citep{kim2021explaining}, and internal activation steering can change vision-language-action behavior\citep{haon2025mechanistic}. Together, these studies motivate specifying the behavioral quantity before interpreting a score.

% audit-anchor: intro-identity
\subsection{Scoring responses and numerical accuracy}

Hama, Mase and Owen derive interaction-dependent random-order references for unnormalized insertion/deletion areas, attributing and evaluating one scalar function\citep{hama2023deletion}. We separate target and response for vector action discrepancies. Our endpoint-normalized identity describes response changes within range and at overshoots; matched robot contexts allow calibrated ranking comparisons. Changing only the response can move a deletion median across an illustrative bar of 0.40. This bar is not an empirically validated decision rule.

% audit-anchor: intro-numerics
A separate question is whether the numerical calculation recovers the specified attribution. IG's axiomatic conditions require care\citep{lundstrom2022rigorous}; baseline and path choices affect interpretation\citep{akhtar2023credible}, and completeness does not guarantee usefulness for a chosen end-task\citep{bilodeau2024impossibility}. Exact integration for piecewise-linear networks exposes sampling errors\citep{sotoudeh2019linear}. Ground-truth benchmarks\citep{arras2022clevrxai} and synthetic sanity simulations\citep{kim2022sanity} offer criteria distinct from passing general checks. Earlier work examines budget-dependent completeness\citep{makino2024integration} and changes integration steps to reduce explanation noise\citep{yang2023idgi}.

We therefore study response choice and numerical recovery separately, using an exact identity, saved-policy rescoring, matched attribution methods and numerical comparisons. Accurate recovery of an integral, stable rankings and favorable perturbation scores are distinct outcomes. The experiments establish effects conditional on their recorded contexts; they neither establish general ranking superiority nor validate the numerical accuracy of the original saved rankings.

\section{Methods}

\subsection{Research design and provenance}

% audit-anchor: historical-cohorts
An episode is one simulated task attempt; a call is one policy prediction of an action chunk. The original evidence consists of two unsuccessful PickCube cohorts, each with \RescoreEpisodes{} episodes and \RescoreCalls{} calls. One cohort used Q rankings and the other N rankings. Both recorded the model as the released RDT-170M\citep{rdt170mrelease}. Shared environment-seed blocks do not make the cohorts matched: vision baseline residuals differ in every aligned call, and their log correlation falls from \CohortInitialCorrelation{} at call 0 to 0.289 at call 2. Original observations and diffusion-noise arrays are unavailable. Rescoring reproduces recorded response changes, not the original policy executions.

% audit-anchor: new-contexts
We also rescore saved RDT-1B PickCube runs and RDT-170M PegInsertionSide and PickSingleYCB runs. The new experiment, R1, groups its runs into three banks. P uses RDT-170M on PickCube (60 episodes, 120 contexts); B1 uses the authors' RDT-1B checkpoint on PickCube (40 episodes, 80 contexts); S uses RDT-170M on StackCube (30 episodes, 60 contexts). With 21 preserved Month 8 contexts, R1 has 281 contexts in total. The new banks uniformly select two executed calls per episode under a rule locked before collection, while preserving every executed call. Table~\ref{tab:r1-experiments} separates experiment sources and estimators; Table~\ref{tab:r1-identities} summarizes provenance. Full hashes, settings and status evidence accompany the archive.

\subsection{Targets, features and numerical estimators}

% audit-anchor: target-setting
We hold context $c$, the model, diffusion noise and other modalities fixed while changing one input modality. Let $g(u)$ predict the active action chunk when that modality is replaced by $u$. Its actual input is $x$, its baseline is $x'$, and the fixed reference action is $a=g(x)$. The chunk has 64 timesteps and eight active action coordinates, so $d_a=512$. ManiSkill3\citep{tao2024maniskill3} executes every fourth action, up to 16 steps per call and 400 steps per episode. Define
\begin{equation}
% audit-anchor: eq-targets
 r(u)=\|a-g(u)\|_2^2,\qquad Q(u)=-\frac{r(u)}{2d_a},\qquad N(u)=-\sqrt{r(u)+\epsilon},\quad\epsilon=10^{-12}.
\label{eq:targets}
\end{equation}
% audit-anchor: target-interpretation
Q is an auxiliary action discrepancy, not a policy log likelihood. The reference action is computed once with fixed noise. Figure~\ref{fig:r1-design} shows how the attribution target and scoring response enter different stages of the evaluation.

\begin{figure}[htbp]
\centering
\includegraphics[width=0.90\linewidth]{figures_revision/r1_design.pdf}
% audit-anchor: fig-design
\caption{\textbf{Attribution and scoring use separate choices.} \textbf{A)} A fixed context produces rankings and intervention actions. The same actions can be scored with Q or N. \textbf{B)} In the zero-stabilizer limit, normalized Q minus N is nonnegative within range and negative beyond the all-baseline residual. \textbf{C)} In a constructed two-feature action map, exact-IG shares divided by each target's endpoint gap reverse order. This is not an observed PickCube ranking reversal.}
\label{fig:r1-design}
\end{figure}

% audit-anchor: features
For vision, the groups are 729 adapted patch tokens from one external image; five other camera slots remain fixed backgrounds. Replacement uses matching adapted tokens from a gray image. SigLIP\citep{zhai2023siglip} and T5-XXL\citep{raffel2020t5} supply the image and language representations. Language attribution acts on attended token positions after the adaptor, so replacement does not rerun the encoder. Historical Q-ranked runs used encoded padding/end-of-sequence tokens; N-ranked runs used the authors' precomputed embedding with a zeroed placeholder baseline. State groups are eight active normalized coordinates, differentiated through the state adaptor against zero. These baselines define comparisons rather than unique neutral inputs\citep{sturmfels2020visualizing}; paths through representation space need not encode valid language\citep{sanyal2021discretized}.

% audit-anchor: integral-introduction
For target $F$, IG and the historical endpoint-inclusive estimator are
\begin{equation}
% audit-anchor: eq-integral
 A_i^F=(x_i-x_i')\int_0^1 f_i(\alpha)\,d\alpha,\qquad
 E_{i,m}=\frac{x_i-x_i'}{m+1}\sum_{j=0}^{m}f_i(j/m),
\label{eq:ig}
\end{equation}
% audit-anchor: integral-relation
where $f_i(\alpha)=\partial_i F(x'+\alpha(x-x'))$. The trapezoidal estimate $T_{i,m}$ gives half weight to endpoints\citep{trefethen2014trapezoidal}; exactly,
\begin{equation}
% audit-anchor: eq-endpoint
 E_{i,m}=\frac{mT_{i,m}+(x_i-x_i')[f_i(0)+f_i(1)]/2}{m+1}.
\label{eq:endpoint}
\end{equation}
% audit-anchor: historical-estimator
The extra endpoint term in the historical estimator can cause first-order error. Historical $m=64$ bf16 runs replaced nonfinite gradients with zero and did not count them. The numerical accuracy of the saved headline rankings is unverified.

% audit-anchor: r1-estimators
R1 labels its numerical variants A0--A4. A0 is the historical kernel. A1 uses reduced-precision bfloat16 (bf16) forward computation with 32-bit floating-point (fp32) accumulation, and A2 uses fp32 forward computation. A3 uses Gauss-Legendre integration with 32, 64 and 128 nodes; A4 uses adaptive Gauss-Kronrod integration. A1 and A2 share 513 nodes, allowing nested trapezoidal and endpoint-inclusive rules through 512 intervals and midpoint rules through 256. A2 covers 12 P contexts and the 21 preserved contexts. Nonfinite values are counted at every evaluated node and never replaced.

A1 T512, the 512-interval trapezoidal estimate, is a finite-budget comparator. An fp32 reference is qualified only when A4 converges and A4, GL128 (128-node Gauss-Legendre) and A2 T512 agree pairwise within relative L1 error $10^{-3}$. This requires agreement among three numerical procedures, not convergence of A4 alone.

\subsection{Interventions, calibration and statistics}

% audit-anchor: intervention-definition
Insertion restores groups from the baseline; deletion replaces groups in the actual input. To rank groups, we sum their absolute attribution coordinates. Mean path gradients omit IG's input-difference factor. With all-baseline squared residual $B=r(x')>0$, the normalized response and paired response difference are
\begin{equation}
% audit-anchor: eq-normalization
 C_S(u)=\frac{S(u)-S(x')}{S(x)-S(x')},\qquad
 \Delta=\mathrm{AUC}_Q-\mathrm{AUC}_N.
\label{eq:normalization}
\end{equation}
% audit-anchor: overshoot-definition
An overshoot moves the prediction farther from the reference action than replacing every feature with its baseline, so $r>B$. Normalization is undefined when $B=0$. AUC combines responses across intervention fractions using trapezoidal weights. Larger insertion areas and smaller deletion areas are conventionally favored.

% audit-anchor: intervention-schedule
The saved nominal schedule is 0, 1, 5, 10, 20, 30, 50, 75 and 100\%. Historical intermediate group counts use $k=\max(1,\mathrm{round}(Gp/100))$, with ties rounded to even. Pinned tokenization gives G=20, 30, 25 and 16 for PickCube, StackCube, PegInsertionSide and PickSingleYCB. Thus 1\% and 5\% select one group for G=16,20,25; all 3,000 headline language curves have equal saved responses there. No such equality occurs in the 800 StackCube curves. This recovers the rule, not missing historical masks. Saved analyses retain nominal weights; R1 uses preserved masks and realized fractions, with nominal-axis sensitivity results.

% audit-anchor: methods-design
R1 compares seven rankings: Q/N IG and Q/N mean path gradient (PG) at A1 T512, input difference, and historical Q/N IG at A0m64. Controls comprise 32 random vision orders, 64 language orders and the exact random-order average for eight state groups. Fixed controls use raster/reverse/centre-out vision orders, forward/reverse token orders and forward/reverse joint orders.

We express performance relative to the random control as \emph{advantage}: method-minus-random AUC for insertion, and random-minus-method for deletion. The preferred method has the highest episode-mean advantage on common complete cases. Subtracting the same reference cannot reorder methods within one response. We therefore compare response choice, z-scaling by the random-order standard deviation (random-SD), population and illustrative 0.4/0.5 deletion bars separately.

% audit-anchor: statistics-design
We use an episode percentile bootstrap with 10,000 draws. The seven primary P vision-deletion contrasts use Bonferroni alpha 0.05/7; intervals comparing the highest two means use 0.05/4 across response/direction cells. Other intervals are descriptive, and best-method ties remain undetermined. Coverage was simulated before unblinding; the plan and amendments precede the results they govern.

Historical rescoring uses bootstrap seed 0 and R1 uses seed 930011. Neither set of intervals captures training-run, checkpoint or wider task variation. We retain all finite tails and all eight dependent headline cases. The emphasis on medians and positive shares was chosen retrospectively.

\subsection{Diagnostic scope and ethics}

% audit-anchor: diagnostic-definitions
The diagnostics answer separate questions. Completeness measures $|\sum_iA_i-[F(x)-F(x')]|/|F(x)-F(x')|$, comparing the attribution sum with the target's change from baseline to actual input. Coordinate change measures differences in individual attribution values using relative L1 differences. Ranking comparisons use Spearman, top-group overlap and intervention-mask Jaccard. We recompute normalized-AUC changes separately, using the same model calculation for scoring. Zero denominators remain undefined. The 1\% completeness and 0.01 AUC-change criteria are study-specific diagnostics, not accuracy guarantees. We also retain RMS discrepancy in physical response units. Its unstabilized normalized area equals N's unstabilized area, so it supplies no independent normalized metric.

% audit-anchor: offline-sample
The earlier offline fp32 sample is separate from these experiments. It contains 12 completed RDT-170M contexts per modality and target, drawn from six episodes across four tasks, and no completed RDT-1B context. Its cached-function and budget comparisons demonstrate possible failures, not their prevalence in the original rankings or diffusion policies generally. Full check results remain archived. All experiments use simulation; no human or animal subjects were involved and no IRB approval was required.

\section{Results}

\subsection{Response identity and saved-curve effects}

% audit-anchor: identity-introduction
Under exact self-reference, Equation~\ref{eq:normalization} gives
\begin{equation}
% audit-anchor: eq-identity
 C_Q-C_N=\frac{(\sqrt{r+\epsilon}-\sqrt\epsilon)(\sqrt{B+\epsilon}-\sqrt{r+\epsilon})}{B}.
\label{eq:identity}
\end{equation}
% audit-anchor: identity-results
The response difference is positive for $0<r<B$, zero at the endpoints and negative at overshoots. With nonnegative AUC weights, a fully in-range curve therefore has $\Delta\ge0$; the inequality is strict if an interior residual receives positive weight. For the same ranking, a lower area favors deletion but disfavors insertion. The pointwise upper bound is 1/4, and endpoint weights tighten the saved-schedule bound to 0.2175. None of these statements depends on IG accuracy.

% audit-anchor: analytic-random-reference
An additive equal-feature policy illustrates why a random-order reference need not be 0.5. Squaring the action discrepancy in Q introduces interactions. At 100 features, every ordering gives AUC 0.65976 on the saved schedule, compared with 0.5 for unstabilized N. These are analytic reference values, not measured RDT controls. Hama's interaction-dependent expectation likewise rules out treating 0.5 as universal; the bar of 0.40 remains illustrative.

% audit-anchor: saved-results
All eight paired medians are positive, ranging from \PairedMedianMin{} to \PairedMedianMax{}. They quantify the size of a response shift whose fully in-range direction was already predicted. Positive shares range from \PositiveShareMin{}\% to \PositiveShareMax{}\%, and overshoots occur in \OvershootShareMin{}\% to \OvershootShareMax{}\% of calls (Figure~\ref{fig:r1-saved-geometry}; Table~\ref{tab:r1-saved-summary}). Extreme calls make six means negative. For Q-ranked vision insertion, the mean is $-17.10$ and the median 0.104; first calls contribute $-16.92$ on the same 750-call denominator. Neither cohort establishes ranking superiority.

Within the primary family, both T512 IG methods exceed random under scoring response N, but neither separates from random under Q. The N-target rankings (IG-N) have higher measured advantage than the Q-target rankings (IG-Q) under either scoring response. For Q scoring, the interval for IG-Q minus IG-N ends at $-0.0115$. \subsection{Numerical accuracy and separate diagnostic outcomes}

% audit-anchor: endpoint-example
The reviewer's linear example isolates the endpoint issue. For $g(u)=u$, baseline 0 and input 1, exact N attribution is approximately 0.999999. At $m=64$, endpoint-inclusive averaging gives 0.984615 (a 1.54\% shortfall), compared with 0.992187 for trapezoidal integration, 0.99999999984 for midpoint and 0.9999999958 for Gauss-Legendre. The narrow endpoint transition explains why equal endpoint weights matter even with exact gradients.

% audit-anchor: historical-completeness
In the saved historical vision calls, median completeness residuals are 1.96\% for Q-ranked and 4.76\% for N-ranked calls; 77.2\% and 99.6\% exceed 1\%. Attribution sums fall short of endpoint gaps in 87.5\% and 99.1\%. Every stored sum is bf16-valued, but storage rounding alone cannot explain this one-sided deficit.

% audit-anchor: precision-results
The new P vision comparisons separate the number of integration intervals from the precision of the model calculation. With A1 bf16 forward computation, increasing trapezoidal intervals from 64 to 512 barely reduces median completeness residuals: from 0.0403 to 0.0351 for N and from 0.00865 to 0.00834 for Q. With A2 fp32, the residuals fall from 0.0154 to 0.00192 for N and from $2.61\times10^{-4}$ to $3.21\times10^{-6}$ for Q (Figure~\ref{fig:r1-numerics}). The same floor-versus-decrease pattern holds on the matched 12 contexts.

Historical maps differ from the bf16 T512 comparator by median relative L1 0.0207 (N) and 0.0182 (Q). Against fp32 T512, the corresponding 12-context medians are 0.0603 and 0.0321. Forward precision therefore limits these bf16 comparisons; adding nodes alone does not remove the floor.

% audit-anchor: ranking-diagnostics
Stable rankings can still give sensitive scores. Comparing A0 with A1 T512 on 120 P vision contexts gives median group Spearman about 0.999975 under both targets and median top-5\% overlap of 1. Yet N-target deletion AUC changes exceed 0.01 in seven contexts scored with N and 12 scored with Q; Q-target counts are four and 12. The maximum Q-scored deletion change for the Q-target comparison is 221.03. Completeness, coordinate change, ranking stability and AUC sensitivity therefore require separate reporting.

% audit-anchor: nonfinite-diagnostics
No NaN or infinity occurs at 815,210 evaluated nodes. A4 converges in all 48 reference comparisons, but only 5 of 24 N comparisons meet the strict three-way qualification. Convergence alone does not establish the reference. A0 residuals depend on GPU summation order, so the per-context fp32-sum alternative is retained. No fp64 model run was performed.

The separate earlier offline fp32 sample also shows that repeated equality checks can pass while budget comparisons fail. This limited sample does not estimate failure rates. The short appendix gives constructed exact-ranking reversal and aliasing examples, not observed robot-policy reversals.

\section{Discussion}

% audit-anchor: discussion-evidence
The analytic identity isolates a scoring effect with unchanged actions and arbitrary rankings. Saved unsuccessful runs measure its size and tails. Successful 1B episodes and additional tasks broaden the observed scope without implying universal effect sizes. The matched R1 study addresses the practical comparison among methods: changing the response can change the preferred method after response-matched calibration. Most intervals comparing the highest two means still include zero. Selecting the highest mean is therefore weaker evidence than establishing a clear winner.

% audit-anchor: discussion-context
Hama's random-order result concerns feature interactions and unnormalized full-prefix areas. Their sufficient condition starts with an additive inner model on binary features and applies a differentiable, strictly increasing transform. The IG argument extends the inner model affinely along the path. This gives the gradients a common coordinate order when $h'>0$. Our construction falls outside that condition because its path-gradient direction varies.

Our findings concern separate targets and responses, endpoint normalization, overshoots and numerical recovery in a vector-output policy; they do not replace general interaction results. We hold interventions fixed to isolate the response, distinguishing this question from intervention and metric studies. Unlike exact-integration work, our finite diagnostics expose limitations without certifying coordinates. No model-weight randomization study was performed\citep{adebayo2018sanity}.

% audit-anchor: reporting-guidance
A practical evaluation should specify its target, response, reference, noise, groups, baselines and masks. Rankings should be compared in identical contexts with response-matched random and fixed controls. Reporting should include undefined gaps, unnormalized residuals, medians and full tails alongside means. Episode-level resampling respects repeated calls. Completeness, coordinate convergence, rank stability and perturbation-score stability should remain separate across budgets and precisions. Passing a finite set of checks guarantees neither a correct integral nor improved robot behavior.

\subsection{Limitations and conclusion}

% audit-anchor: limitations
The numerical accuracy of the saved headline rankings remains unverified, and R1's regeneration success cannot restore their missing original inputs. The historical cohorts are not matched ranking comparisons. All original headline episodes, P and S fail; successful evidence rests mainly on historical 1B and B1, with differing seeds, language inputs and runtimes. Month 8 samples are too small for population inference. Partially replaced inputs have no demonstrated causal explanation here, and the offline fp32 sample and R1 subsets establish possible outcomes rather than general numerical failure frequencies.

% audit-anchor: conclusions
The exact identity establishes the direction of fully in-range response changes. Saved and new experiments establish conditional effects in their recorded contexts, including successful 1B episodes and response-dependent preferred methods. Numerical comparisons and counterexamples establish limits on particular estimators and checks. Together, these findings support explicit response calibration and qualified numerical reporting. They do not establish general ranking superiority or improved task success.

\section{Short analytic proofs}

% audit-anchor: proof-identity
Set $\eta=\sqrt\epsilon$, $b=\sqrt{B+\epsilon}$ and $z=\sqrt{r+\epsilon}$. Because $B=(b-\eta)(b+\eta)$, subtracting the normalized responses gives $(z-\eta)(b-z)/B$, proving Equation~\ref{eq:identity}. In range its maximum is $(b-\eta)/[4(b+\eta)]\le1/4$. Beyond range it is negative. The saved schedule gives zero endpoint differences total weight 0.13, hence $\Delta\le0.87/4=0.2175$. If B=0 normalization is undefined. Equal saved 1\%/5\% values make deletion of the 1\% node change their combined weight by 0.02, bounding its in-range paired effect by 0.005.

% audit-anchor: proof-reversal
For scalar action examples set $d_a=1$. With $g(x_1,x_2)=x_1^2+(4/5)x_2$, baseline (0,0), input (1,1) and reference 9/5, polynomial integration gives $A^Q=(23/30,64/75)$. Writing $\rho(\alpha)=(1-\alpha)(1+\alpha+4/5)$, N's gradient is $\rho(\alpha)(2\alpha,4/5)/\sqrt{\rho(\alpha)^2+\epsilon}$. The inequality $\rho\ge(4/5)(1-\alpha)$ bounds the coordinate deficits from (1,4/5) by $2.5\times10^{-6}$ and $10^{-6}$ at the chosen epsilon. Thus N ranks feature 1 first while Q ranks feature 2 first. This is a constructed possibility, not an observed PickCube reversal.

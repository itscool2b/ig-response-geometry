# Historical figures

Every figure in this directory belongs to superseded analyses. Old log-pi/nats labels, efficacy thresholds, pass/fail annotations and causal interpretations are retained as historical content, not current scientific conclusions. In the current study, the historical logpi score is an auxiliary action discrepancy rather than a policy log likelihood.

Read [the current paper](../../paper/paper.pdf) and [the current analysis guide](../../analysis/revision/README.md). These figure bytes are preserved unchanged. Current manuscript figures are in `paper/figures_revision/`.
